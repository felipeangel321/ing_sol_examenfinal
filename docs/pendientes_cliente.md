# Pendientes por aclarar con el cliente

Marca cada punto cuando tengas la respuesta y anótala al lado.

## Alcance

- [ ] ¿Quién es el primer corredor y qué seguros vende?
- [ ] ¿Qué necesita gestionar el corredor? Por ejemplo: solicitudes, clientes, renovaciones o siniestros.

## Documentación

- [ ] ¿Qué documentos hay por cada seguro? Por ejemplo: condiciones generales, coberturas, exclusiones o preguntas frecuentes.
- [ ] ¿Quién los entrega y quién los mantiene al día?
- [ ] ¿Se pueden usar esos documentos con un servicio de IA externo?
- [ ] La póliza de ejemplo recibida parece ser de un cliente real, con sus datos personales. ¿Hay autorización para usarla, o pueden enviar una anonimizada o solo las condiciones generales?
- [ ] ¿Con qué aseguradoras trabaja el corredor? La póliza de ejemplo es de una sola, y sus condiciones no valen para las demás.
- [ ] ¿Qué planes vende de cada una, y cuáles son sus deducibles y coberturas?

## Solicitudes

- [ ] ¿Qué significa "procesar" una solicitud: enviarla al corredor por correo, registrarla en un sistema o cotizar con la aseguradora?
- [ ] ¿Qué datos pide cada seguro?
- [ ] ¿El corredor usa hoy algún sistema (CRM, planillas o portales de aseguradoras)?

## Límites de los agentes

- [ ] ¿Qué no debe responder o prometer el agente? Por ejemplo: precios, recomendar una póliza o confirmar si un siniestro está cubierto.
- [ ] ¿Cuándo debe derivar a una persona, y por qué canal?

## Datos personales y normativa

- [ ] ¿Qué exigen la CMF y la ley de datos personales para este uso? Conviene revisarlo con un abogado o con el corredor, sobre todo en vida y salud, porque esos datos son especialmente sensibles.
- [ ] ¿Cuánto tiempo se guardan las conversaciones y quién puede verlas?

## Sitio

- [ ] ¿El primer corredor tiene dominio y marca, o hay que crearlos?
- [ ] ¿Quién paga y administra el servidor y el consumo del modelo de IA?
